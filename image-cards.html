我不自己抽卡
只看最後的結果

一套圖卡生成工作流：人只負責講需求，Claude 寫畫圖指令並負責審圖，ChatGPT 只負責畫。
含完整指令模板、角色設定卡、五條審核標準與重試上限。

這套流程解決什麼問題？

一句話說完：把「抽卡」變成「交件」

自己跟繪圖模型來回，大部分時間不是花在創意上，而是花在重複勞動：同一段指令改第七次、每張圖都要自己看有沒有簡體字、帽子又畫錯、文字又被角色擋住。本來是要產一張圖卡，最後變成一個下午。

解法不是換更好的模型，是把角色拆開。讓寫指令和審圖的那個人（Claude）跟畫圖的那個人（ChatGPT）分開，然後把審核標準寫死。人只出現在頭尾兩端：開頭講需求，結尾看成品。

🔁 核心閉環

講需求 → 寫指令 → 畫 → 審 → 沒過就改指令重畫 → 過了才交到人手上

關鍵在「審」這一步必須是機械式的、有明文標準的，而不是憑感覺覺得好不好看。
標準寫得夠死，退圖和重畫就不需要人介入。

💡 為什麼不讓畫圖的那端自己審？

畫的和審的是同一個，就會自己說自己畫得好。審核必須由沒有畫這張圖的那一方執行——這是分工的重點，不是多一道工。

📖 完整流程與標準
  1. 四步流程（從需求到交件）
  2. 畫圖指令要寫滿四件事（含可複製模板）
  3. 角色設定卡（長相寫死，不給自由發揮）
  4. 五條審核標準（怎麼算過、怎麼算退）
  5. 重試上限與換路規則
  6. 怎麼接上 Codex CLI

1. 四步流程

人只出現在第 1 步和最後驗收

人跟 Claude Code 講需求

三件事講清楚就夠：要什麼圖、用在哪、給誰看。不需要自己想構圖、不需要自己想比例、不需要先寫英文 prompt。

Claude 把需求寫成完整的畫圖指令

補齊四件人沒講的事：比例、構圖、角色長相、圖上要放的字。這一步是整套流程的品質來源——指令寫得完整，退圖率就低。

Claude 用 Codex CLI 叫 ChatGPT 畫

用 ChatGPT 帳號登入就能用，不用另外申請 API key（需付費方案，見 第 6 節）。畫圖端不參與討論，收到指令就畫。

圖回來，Claude 照標準審

五條標準逐條檢查。沒過就改指令重畫，不拿去問人、不降低標準放行。過了才交到人手上。

🎯 人在這套流程裡的工作量

開頭一句需求，結尾看一張圖。
中間的指令撰寫、呼叫、檢查、退圖、重寫、再呼叫，全部不經過人。

2. 畫圖指令要寫滿四件事

比例、構圖、角色長相、圖上要放的字

人講的需求通常是「幫我做一張介紹咪卡的 IG 圖卡」。這句話缺的東西比有的多。Claude 要補的就是這四項：

  • 比例——決定於要發的平台，不是決定於好不好看
  • 構圖——角色放哪、佔多大、哪裡留白給文字
  • 角色長相——逐條寫死，含「不是什麼」
  • 圖上要放的字——只放這幾個字，一字不多

寫成可以直接貼給畫圖端的模板長這樣：

# 畫圖指令模板（直接貼給畫圖端）
【比例】 直式 4:5（1080 × 1350 px） 【用途】 IG 貼文第 1 張，給還沒用過 AI 的人看 【角色設定卡 — 逐條照畫，不要自由發揮】 咪卡：黑貓、金黃色眼睛、米褐色偵探帽 （偵探帽 = 鹿皮獵帽 deerstalker，不是棒球帽、不是紳士帽） 【構圖】 角色放右下角，佔畫面約 1/4 左上方留白給主標題 角色不可壓到任何文字，也不可搶走主視覺 【圖上文字 — 只放這幾個字，全部繁體中文】 主標：（填入） 副標：（填入） 【禁止】 不要九宮格、不要多格分鏡、不要拼圖——一張圖就是一張卡 不要簡體字、不要用英文代替中文 不要加沒有要求的文字、logo、浮水印
💡 「禁止」這段不要省

繪圖模型最常出的錯都是沒被禁止的自由發揮：自己拼成九宮格、自己加英文標語、自己換一頂好看的帽子。把禁止寫在指令裡，比事後退圖便宜。

3. 角色設定卡

長相寫死一次，之後每張圖原封不動貼進去

角色跨圖不一致，是圖卡系列最明顯的破功點。解法是把長相固定成一張設定卡，每一張圖的指令都原封不動貼同一段文字，不要每次重寫、不要改用詞。

🐈‍⬛ 範例：咪卡

黑貓 · 金黃色眼睛 · 米褐色偵探帽

三項全部要對上才算過。帽子畫成棒球帽就退——這不是「風格差異」，是角色錯了。

設定卡寫法上有兩個細節值得做：

  • 每一項都附「不是什麼」：「米褐色偵探帽（鹿皮獵帽，不是棒球帽）」比單寫「偵探帽」有效得多
  • 項目不要超過五項：寫太多，模型會開始取捨，反而丟掉關鍵特徵

4. 五條審核標準

圖卡用這五條——逐條過，不是整體感覺

✓ 怎麼算過 ✕ 怎麼算退
角色 長相跟設定卡逐條對上 黑貓變虎斑、偵探帽畫成棒球帽
文字 繁體中文看得懂，無亂碼 筆畫糊掉、錯字、出現簡體字
比例 直式 4:5 或橫式 16:9 比例不符平台、主體被裁掉
單張 一張圖就是一張卡 拼成九宮格、多格分鏡
構圖 角色不擋字，也不搶主視覺 角色壓在標題上、文字被遮住
⚠️ 五條是「全部要過」，不是「過三條就算好」

任何一條沒過就是退。只要開始通融，標準就會一路鬆到跟沒有標準一樣——而且是人要花時間重新看每一張。

這五條是圖卡用的。如果是別的用途（例如橫幅、封面、產品圖），標準要換，但原則一樣：明文、可逐條判斷、不靠感覺。

5. 重試上限與換路規則

同一張圖、同一種改法，失敗兩次就換路

沒有上限的重試會變成無聲的燒時間：同一個問題改第九次，每次都差一點。所以規則寫死：

同一種改法，最多試兩次

第二次還是沒過，就不要再用同一種方式改指令。問題大概不在措辭，在要求本身太難。

換路一：縮短圖上的字

文字類失敗（亂碼、糊掉、簡體）絕大多數是字太多。砍到剩主標，通常就過了。

換路二：把畫面改簡單

構圖類失敗（擋字、搶主視覺）靠減少元素解決：少一個物件、背景再空一點、角色再小一點。

兩條換路都走完，才叫人來看

這時候回報的不是「畫不出來」，而是試過哪幾種、各差在哪——人要決定的是放寬哪一條標準，或者改需求。

💡 上限的真正作用

不是省 token，是保護人的注意力。沒有上限，壞掉的任務會一直卡在那裡，不會冒泡到人面前。

6. 怎麼接上 Codex CLI

用 ChatGPT 帳號登入就能用，不用另外申請 API

這套流程裡 Claude 要能自己把指令送到畫圖端。808AI 走的路是 OpenAI 的 Codex CLI：用你現有的 ChatGPT 帳號登入即可，不需要另外去申請、綁定 API key。

# 安裝（擇一）
npm install -g @openai/codex # 或者 macOS / Linux 一行安裝 curl -fsSL https://chatgpt.com/codex/install.sh | sh # 或者 Homebrew（注意是 --cask） brew install --cask codex
# 登入：跑起來之後選「Sign in with ChatGPT」
codex

官方文件的登入方式是直接執行 codex，在選單裡選「Sign in with ChatGPT」，會跳瀏覽器完成授權——不是打 codex login。登入後 Claude Code 就可以在終端機裡呼叫 codex，把寫好的整段指令送過去。

⚠️ 需要付費的 ChatGPT 方案

官方說明是「建議登入 ChatGPT 帳號，以 Plus、Pro、Business、Edu 或 Enterprise 方案使用 Codex」。免費帳號能不能用，官方頁面沒有明講——這部分請以你自己的帳號實測為準。

⚠️ 老實說：Codex CLI 官方定位是「寫程式的 agent」

OpenAI 官方 README 把 Codex CLI 描述為在你電腦上本機執行的 coding agent，文件裡並沒有記載產圖功能。這條「用 Codex CLI 叫 ChatGPT 畫圖」是 808AI 自己接出來的路徑，不是官方寫在文件上的用法；而且 Codex CLI 更新很快，實際怎麼叫得動圖像生成會隨版本變動。裝好後請先跑 codex --help 對一次你這版的能力，不要照抄任何舊版旗標。

💡 沒有 Codex CLI 也能跑這套流程

自動化只是省掉複製貼上。真正產生品質的是指令模板、設定卡和五條標準——手動把指令貼到 ChatGPT、把圖貼回 Claude 來審，流程一樣成立，只是慢一點。對不確定 Codex 這條路的人，建議先用手動跑通，確認標準有效，再去自動化。

整套流程能自己跑的三個前提

少任何一個，人就會被拉回中間

📋

標準是明文的

五條標準寫在紙上，每條都能單獨判斷「過 / 退」。靠感覺的標準沒辦法交給別人執行。

🚧

審的人不是畫的人

畫圖端不參與判斷要不要重畫。自己審自己，標準一定會鬆。

⏱️

失敗有上限

兩次換路、換完才找人。沒有上限的重試等於把問題藏起來。

🎴

角色長相固定一次

設定卡原封不動貼進每張指令。每次重寫長相，就等於每次重新抽卡。
