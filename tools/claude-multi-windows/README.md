# Claude 多帳號工具（Windows）

在同一台 Windows 電腦上，同時開兩個以上的 Claude 帳號。每個帳號有自己的桌面捷徑、登入狀態和本機資料，互不干擾。免費，不需要系統管理員權限。

---

## 一鍵安裝

1. 按鍵盤 `Win` 鍵，輸入 **PowerShell**，按 Enter 打開（不用「以系統管理員身分執行」）
2. 複製下面這一行，在 PowerShell 視窗按滑鼠右鍵貼上，再按 Enter：

```powershell
irm https://raw.githubusercontent.com/Rirychh/-/main/tools/claude-multi-windows/install.ps1 | iex
```

3. 看到「安裝完成」後，選單會自動打開

安裝會做三件事：
- 把工具放到 `%LOCALAPPDATA%\ClaudeMulti`
- 在桌面和開始功能表建立「**Claude 多帳號工具**」
- 打開選單

> 想更新到最新版：再貼一次同一行指令就好，已經建立的帳號不會受影響。

---

## 使用方法

### 第一次：新增第二個帳號

你原本的 Claude 桌面版就是第一個帳號，**不用動它**。以下是新增「第二個」帳號：

1. 打開「Claude 多帳號工具」，輸入 `1`（新增帳號）
2. **帳號代號**：輸入英文代號，例如 `work`
3. **備註**：例如「公司帳號」，可以留空直接按 Enter
4. **模式**：輸入 `1`（官方桌面版），第一次建議選這個
5. **建立桌面捷徑？** 按 Enter（代表 Yes）
6. **現在開啟並登入？** 按 Enter
7. 會開一個新的 Claude 視窗，在裡面**登入第二個帳號**
8. 瀏覽器問「要開啟 Claude 嗎？」時，按「**開啟**」
9. 登入完成後，回到工具視窗按 **Enter**

完成！桌面上會多一個「**Claude - work**」。

### 之後每天使用

| 想開 | 點這個 |
|------|--------|
| 第一個帳號 | 原本的 Claude 圖示 |
| 第二個帳號 | 桌面上的「Claude - work」 |

兩個可以**同時開著**，各自獨立。想加第三個、第四個帳號，重複「新增帳號」就好。

### 選單功能一覽

| 選項 | 功能 |
|------|------|
| 1 | 新增帳號 |
| 2 | 開啟帳號（不用捷徑也能開） |
| 3 | 重新登入帳號（登入失敗或被登出時用） |
| 4 | 建立桌面捷徑（捷徑不小心刪掉時用） |
| 5 | 列出所有帳號 |
| 6 | 刪除帳號 |
| 7 | 解除安裝這個工具 |
| 0 | 離開 |

## 兩種模式差在哪

| 模式 | 開出來的是 | 適合 |
|------|-----------|------|
| **1. 桌面版**（desktop） | 官方 Claude 桌面版 | 要用 Claude Code、Cowork、MCP 等桌面功能 |
| **2. 網頁版**（web） | Edge／Chrome 的 claude.ai 獨立視窗 | 只聊天；或桌面版模式不能用時 |

## 遇到問題

**第一次開啟時出現「警告：資料夾還是空的」**
代表你的 Claude 版本不支援分開帳號。輸入 `6` 刪掉這個帳號，再輸入 `1` 重建，模式選 `2`（網頁版）。

**登入後跑回第一個帳號，或登入卡住**
輸入 `3`（重新登入帳號）再試一次。登入時不要同時開其他 Claude 帳號。

**出現「你的 Claude 是 Microsoft Store 版」**
Store 版不支援桌面版模式，工具會自動改用網頁版模式。

**PowerShell 顯示紅字錯誤**
把整段紅字截圖或複製下來，回報給開發者。

**沒辦法用一鍵安裝（公司電腦擋掉）**
到 GitHub 下載這個資料夾裡的 `ClaudeMulti.ps1` 和 `ClaudeMulti.bat`，放在同一個資料夾，雙擊 `ClaudeMulti.bat`。如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

---

## 解除安裝

打開「Claude 多帳號工具」，輸入 `7`，再輸入 `YES`。

會移除：這個工具、所有額外帳號的本機資料和捷徑。
不會動到：你原本的 Claude 桌面版、雲端上的對話紀錄。

---

## 運作原理（給想了解的人）

- **桌面版模式**：用 `--user-data-dir` 參數開 Claude，每個帳號的資料存在 `%LOCALAPPDATA%\ClaudeMulti\profiles\<代號>\data`
- **登入協助**：桌面版登入時，瀏覽器會用 `claude://` 連結把登入結果送回 app，這個連結預設只送到原本的帳號。登入期間，工具會暫時把 `claude://` 指向新帳號（修改 `HKCU\Software\Classes\claude`），按 Enter 後改回原狀。如果中途關掉視窗，下次打開選單時會自動還原
- **網頁版模式**：用 Edge／Chrome 的 `--user-data-dir` 和 `--app=https://claude.ai` 開一個獨立的瀏覽器設定檔

## 注意事項

- 這不是 Anthropic 官方工具。Claude 更新後，桌面版模式有可能失效，那時改用網頁版模式即可
- 這個工具不會讀取或儲存你的密碼，登入都在 Claude 自己的視窗裡完成
- 使用多個帳號時，請遵守 Anthropic 的使用條款
