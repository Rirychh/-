# 角色設定卡登錄

角色跨圖不一致是圖卡系列最明顯的破功點。解法是把長相固定在這裡，
**每次寫畫圖指令時逐字複製下面的「指令用區塊」貼進去**——不要重寫、
不要換同義詞、不要自己補細節。每次重寫長相，就等於每次重新抽卡。

## 寫設定卡的兩個原則

**每項都附「不是什麼」。** 模型對正面描述的解讀空間很大，負面界定才收得住。
「米褐色偵探帽（鹿皮獵帽 deerstalker，不是棒球帽、不是紳士帽）」比單寫
「偵探帽」有效得多——因為錯誤版本是可以被明確排除的。

**項目上限五項。** 超過五項，模型會開始自己取捨，反而丟掉最關鍵的特徵。
如果角色真的很複雜，選最能一眼認出他的五項，其餘讓它自由。

## 咪卡（Mika）

| 項目 | 設定 | 常見畫錯 |
|------|------|----------|
| 物種 | 黑貓，全身純黑 | 虎斑、黑白賓士貓、深灰 |
| 眼睛 | 金黃色 | 綠色、藍色、琥珀偏橘 |
| 帽子 | 米褐色偵探帽（鹿皮獵帽 deerstalker） | 棒球帽、紳士帽、禮帽 |

### 指令用區塊（逐字複製，不要改寫）

```
【角色設定卡 — 逐條照畫，不要自由發揮】
咪卡：黑貓，全身純黑、金黃色眼睛、戴米褐色偵探帽
（偵探帽 = 鹿皮獵帽 deerstalker，有前後兩片帽簷；
  不是棒球帽、不是紳士帽、不是禮帽）
```

### 審圖時的對照清單

- [ ] 全身純黑，沒有虎斑紋或白色斑塊
- [ ] 眼睛是金黃色
- [ ] 帽子是鹿皮獵帽型的偵探帽，不是棒球帽

三項任一不符就是退。這不是「風格差異」，是角色錯了。

---

## 新增角色時

照上面的格式加一節：表格（項目／設定／常見畫錯）＋ 指令用區塊 ＋ 審圖對照清單。
「常見畫錯」欄位在第一次退圖之後補——實際錯過的版本，比事先想像的更值得寫進去。
