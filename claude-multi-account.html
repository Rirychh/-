Claude 多帳號
一台電腦同時登入兩個帳號

官方 Claude 桌面版一次只能登入一個帳號，換帳號就要登出再登入。
這個工具讓公司帳號和個人帳號同時開著，各自有自己的圖示、登入狀態和資料。

1. 為什麼需要這個工具

官方桌面版目前不支援多帳號

很多人同時有公司帳號和個人帳號。官方 Claude 桌面版一次只能登入一個，要切換只能登出再登入，有時候還會遺失側邊欄和進行中的工作。

👥

同時開著

兩個帳號各開一個視窗，用 Alt-Tab 切換，不用登出。

🗂️

資料分開

每個帳號有自己的資料夾，登入狀態、設定互不干擾。

🎨

一眼分得出來

每個帳號的捷徑和工作列圖示都有彩色小徽章，不會開錯。

✅

免費、免管理員權限

不用付費，也不用「以系統管理員身分執行」，只動到你自己的使用者設定。

2. 一行指令安裝

複製、貼上、按 Enter，大約 10 秒

打開 PowerShell

按鍵盤 Win 鍵，輸入 PowerShell，按 Enter。不用選「以系統管理員身分執行」。

貼上這一行，按 Enter

按下方的「複製」，到 PowerShell 視窗按滑鼠右鍵就會貼上。

# Windows PowerShell
irm https://raw.githubusercontent.com/Rirychh/-/main/tools/claude-multi-windows/install.ps1 | iex

這條指令會做這些事：

  1. 把工具放到 %LOCALAPPDATA%\ClaudeMulti
  2. 在桌面和開始功能表建立「Claude 多帳號工具」
  3. 自動打開選單
💡 想更新到最新版

再貼一次同一行指令就好，已經建立的帳號不會受影響。

3. 新增第二個帳號

你原本的 Claude 就是第一個帳號，不用動它

選「1. 新增帳號」

打開「Claude 多帳號工具」，輸入 1。

取一個代號

只能用英文、數字、- 或 _，例如 work。備註可以寫「公司帳號」，也可以直接按 Enter 留空。

模式選 1（官方桌面版）

第一次建議選這個。兩種模式的差別見第 5 節。

之後的問題都按 Enter

會幫你建立桌面捷徑，並打開一個新的 Claude 視窗。

看到綠字「確認成功」

代表這個帳號的資料存在獨立資料夾，不會影響原本的帳號。

在新視窗登入第二個帳號

瀏覽器問「要開啟 Claude 嗎？」時，按「開啟」。登入完回到工具視窗按 Enter。

⚠️ 瀏覽器要登入「對的帳號」

登入時會跳到瀏覽器。如果瀏覽器已經登入了第一個帳號，請先登出，或改用無痕視窗，不然會登進同一個帳號。

4. 每天怎麼用

點不同的圖示，就是不同的帳號

想開點這個
第一個帳號原本的 Claude 圖示
第二個帳號桌面上的「Claude - work」（圖示右下角有小徽章）
第三個以後重複「新增帳號」，每個帳號都會有自己的捷徑

📌 工作列也分得開

每個額外帳號在工作列上都是獨立的按鈕，有自己的圖示和名稱。把它「釘選到工作列」之後，下次直接點就會開對的帳號。

5. 兩種模式差在哪

新增帳號時要選一種

1. 桌面版2. 網頁版
開出來的是官方 Claude 桌面版Edge／Chrome 的 claude.ai 獨立視窗
Claude Code、Cowork、MCP✅ 都能用❌ 沒有
穩定度Claude 大改版時可能要更新工具最穩定，一定能用
適合大部分人只聊天，或桌面版模式不能用時

6. Microsoft Store 版要多做一步

只有第一次登入額外帳號時要做，之後不用

如果你的 Claude 是從 Microsoft Store 安裝的，工具會自動偵測。第一次登入額外帳號時，會請你在 Windows 設定裡指定一次「登入連結交給誰處理」：

工具會自動打開「預設應用程式」

按 Enter 就會開啟設定頁。

搜尋 claude

在最上面「為檔案類型或連結類型設定預設值」的搜尋框輸入 claude，點出現的「CLAUDE」那一列。

選「Claude 多帳號工具」

按「設為預設值」。如果 Windows 問要不要切換，選「仍要切換」。

💡 不用擔心原本的帳號

設定之後，平常的 Claude 連結還是會開到原本的 Claude。只有在你登入額外帳號時，工具才會把登入結果送給那個帳號。如果它分不出是哪個帳號，會跳出小視窗問你要交給誰。

8. 常見問題

大部分狀況都能自己解決

出現黃字「資料夾還是空的」

代表你的 Claude 版本不支援分開帳號。輸入 6 刪掉這個帳號，再輸入 1 重建，模式改選 2（網頁版）。

登入後跑回第一個帳號，或登入卡住

輸入 3（重新登入帳號）再試一次。確認瀏覽器登入的是第二個帳號（可以用無痕視窗）。

PowerShell 出現紅字錯誤

把整段紅字截圖或複製下來，到 808AI 社群回報。

公司電腦擋掉一行指令安裝

到 GitHub 下載 ClaudeMulti.ps1 和 ClaudeMulti.bat，放在同一個資料夾，雙擊 ClaudeMulti.bat。出現「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。

這個工具會看到我的密碼嗎？

不會。登入都在 Claude 自己的視窗和瀏覽器裡完成，工具不會讀取或儲存你的密碼。

⚠️ 這不是 Anthropic 官方工具

Claude 大改版後，桌面版模式有可能暫時失效，那時改用網頁版模式即可。使用多個帳號時，請遵守 Anthropic 的使用條款。

9. 解除安裝

一個步驟，乾淨移除

打開「Claude 多帳號工具」，輸入 7，再輸入 YES。

  • 會移除：這個工具、所有額外帳號的本機資料和捷徑
  • 不會動到：你原本的 Claude 桌面版、雲端上的對話紀錄

10. Mac 使用者怎麼辦

這個工具只支援 Windows，Mac 有兩個替代方案

💳

Multi-Claude（付費）

第三方 Mac app，一次買斷約 US$20。每個帳號一個獨立 app。非官方工具，購買前請先確認它支援哪些桌面版功能。

🌐

Chrome 設定檔（免費）

建兩個 Chrome 設定檔，各自登入 claude.ai，再用「安裝為應用程式」變成兩個獨立視窗。只能聊天，沒有桌面版專屬功能。

開始用兩個帳號吧
